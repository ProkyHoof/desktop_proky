# 日历计划数据

在桌宠右键菜单中打开“日历计划…”，选择日期后添加计划、勾选完成，并填写当天记录。

- 每天一个 `yyyy-MM-dd.json` 文件，使用 UTF-8，内容包含日期、计划列表、完成状态、当天记录及最后保存时间。
- 编辑后约 0.65 秒自动保存，切换日期和关闭窗口前也会保存；可点击“保存记录”或按 Ctrl+S。
- 已有文件更新时使用原子替换，上一版保存在同名 `.json.bak` 文件中。备份整个目录即可迁移记录。
- 如果文件损坏，界面会标记“读取失败”，保留原文件并禁止覆盖；关闭日历窗口后，可将原文件另存，再用对应备份恢复。
- 正常运行的数据保存在 `%LOCALAPPDATA%\DesktopPet\data\calendar`，与源码和安装目录隔离，不上传网络。此目录仅保留说明文档；旧版个人数据会在首次运行时迁移。预览和测试不会写入真实用户目录。

## Outlook 式工作区与全局管理

- 顶部切换日、工作周、周、月和全部列表，左侧小月历跳转日期，右侧编辑当天详情；窗口可缩放、最大化，详情分隔线可拖动。
- 计划支持可选的 `Start` / `End` 时间字段，使用 `HH:mm`，结束时间可为 `24:00`。旧文件缺失时间字段时仍作为全天计划读取，不改变原有内容。
- 月历双击卡片编辑、双击空白新建；时间轴双击时间段新建、拖动已有卡片改期。拖动保留时长，靠近午夜时会将开始时间提前以保证当天结束。
- 搜索覆盖所有日期，匹配计划、记录正文，也接受 `2026-11`、`2026-11-06` 等日期片段。搜索结果可按状态、类型筛选并按列排序。
- 在全部列表中使用 Ctrl / Shift 多选，然后批量完成、重开、移动到日期、删除。完成、重开和移动仅处理计划；选中的记录可删除，移动计划时保留源日期的记录。
- “撤销批量”恢复本次窗口中最近一次成功的批量操作或拖动；如果相关日期此后已有新修改，会阻止撤销，避免覆盖新内容。
- 每次批量修改和撤销前，都会将受影响日期的完整原内容写入 `history/<时间与编号>/yyyy-MM-dd.json`。写入途中发生错误时尝试恢复已写入日期；若还原受阻，界面会提示需恢复的日期及快照路径。快照不参与正常搜索。
- 快照用于人工恢复：关闭日历窗口，先另存当前文件，再将需要的日期快照复制回本目录对应的日期文件。备份整个目录可以保留原始记录、上一版备份及全局操作快照。

快捷键：Ctrl+F 搜索、Ctrl+N 新建、Ctrl+S 保存、Ctrl+Alt+1/2/3/4/5 切换日/工作周/周/月/全部列表。
