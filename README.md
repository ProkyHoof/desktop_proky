# 桌宠助手

Windows 透明桌面宠物，使用 C#、WinForms 和 .NET Framework 编译。支持骑士的三种发型、键鼠动作反馈、打字表情与露面骑士盔、音乐律动、文字 AI 聊天、日历计划和本地记录。

## 安装与运行

- 系统：Windows 10/11，需启用 .NET Framework 4.x（通常已内置）。
- 安装版：运行 `DesktopPet-1.3.0-Setup.exe`，在安装界面填写目录或点击“浏览…”选择文件夹。默认目录为 `%LOCALAPPDATA%\Programs\DesktopPet`，默认创建桌面快捷方式，并提供开始菜单入口。可在系统“已安装的应用”中卸载。
- 默认目录无需管理员权限；选择受保护的位置时需以管理员身份运行安装程序。个人数据目录会为安装时的 Windows 用户授予写入权限。
- 便携版：解压 `DesktopPet-1.3.0-portable.zip`，运行 `DesktopPet.exe`。配置和日历同样保存在程序所在目录。
- 源码版：双击 `启动桌宠.bat`，首次运行自动构建。源码有更新时会重新编译。
- 安装包和 ZIP 是构建输出，不提交 Git；可从 GitHub Actions 的 `DesktopPet-Windows` 构建产物下载。

右键主菜单提供“皮肤…”“日历计划…”“打字统计…”三个常用入口。“互动设置”集中管理键鼠跟随、音乐律动、按键显示与键鼠设置；“桌面设置”管理大小、置顶、自启动和位置；“AI 与助手”包含接口设置、助手设置与记录、停止当前操作。“闭眼休息”和“退出”可直接点击，监听与音乐信息在“运行状态”中查看。单击人物展开文字输入，Enter 发送；中文输入法选词期间不会发送。拖动人物移动位置。

右键选择“打字统计…”可查看今日、近 7 天、累计次数和月度热力图。每个日期显示具体次数，颜色按固定区间加深；可切换月份、回到今天，点击日期或用方向键查看当天 24 小时的次数明细。

统计单位是实际打字按键次数，不是输入法最终生成的文字数。字母、数字、标点、空格、回车和退格计入；长按自动重复、Ctrl/Alt/Win 快捷键、方向键、功能键和鼠标不计入。仅桌宠运行、开启键鼠跟随且非休息时统计。按事件发生时的系统当地日期和小时归档，每 10 秒及正常退出时保存；强制结束进程可能丢失最近尚未保存的计数。只保存数量，不保存键名、输入内容或逐次按键时间。

持续打字时的露面骑士盔参考服装设定图，保留银白中脊、顶甲浅灰折面与黑色眉缘。只移除遮脸的中央面甲、鼻梁竖条和独立下巴护片内部，露出眼睛、脸颊和嘴巴；下颌线直接沿用原图的两侧灰色护片、原有厚度、折面和底部轮廓。保留部分逐像素来自原素材，不重新绘制或缩窄下颌。顶甲、两侧护甲和下颌部件沿用六块图层依次展开、收回，保留原本表情、眨眼与视线跟随；音乐模式的灯环与音量条仍位于耳侧。新头盔源图、原图与提示词位于 `assets/keyboard-knight/helmet-design/`，当前使用 `silver-knight-original-jaw-source.png`，提示词见 `original-jaw-prompts.json`；运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Prepare-Helmet.ps1` 可依据生成图的透明区域挖空原图，再重新生成六块注册图层。

人物衣装保留红领巾，使用黑色垂褶衣身、象牙白宽松布袖、深色肩片与皮革护腕和黑手套。身体与双臂沿用原素材的注册画布和完整透明轮廓，不改变人物比例、整体大小、肩点或手指位置。设计源图与原素材保留在 `assets/keyboard-knight/outfit-design/`，可用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Prepare-ClothOutfit.ps1` 重新注册运行时素材；源图不进入安装包。

## 皮肤

右键“皮肤…”统一管理外观。整体配色仅提供“经典”“海盗”“赛博”三种：经典为红黑白，海盗为暖金与深红，赛博为青紫霓虹，统一调整围巾、虹膜、键鼠装饰和动作灯效，保留肤色、白色高光与黑色线条。发型可选“利落短发”“层次长发”“蓬松双马尾”；键盘可选“骑士键盘”“羊皮卷”“悬浮投影键盘”，已删除“圆角键帽”和“暗色机械”；鼠标可选“骑士鼠标”“骑士剑鼠标”“全息投影”；鼠标垫可选“骑士鼠标垫”“航海图”“全息电路桌垫”；打字头饰可选“骑士头盔”“海盗帽”“战术全息目镜”；音律可选“节奏光柱”“海浪波纹”“黑客代码流”；听歌配饰可选“原版耳机”“头巾”“神经音频模块”。眼睛仅保留原版圆瞳，默认整体基调仍为红黑白。各项可独立搭配，在右侧动态预览后点击“应用并保存”。关闭窗口不会应用未保存的选择，原“选择发型”菜单已合并到皮肤窗口。

皮肤窗口可预览待机、打字与头饰、音乐律动、休息、鼠标动作与剑光、边打字边听音乐六种状态。预览使用模拟状态，不播放音乐、不监听键鼠、不增加真实打字计数。应用搭配不打断桌宠动作或输入，重启和调整大小后保留所有选择。原版眼睛保留高光、眨眼与视线跟随；旧配置中的单独键鼠/眼睛颜色选项不再使用，默认恢复红黑白和原装造型，新选择保存在 `keyboardShape`（0 骑士键盘、3 羊皮卷、4 悬浮投影键盘，旧 1/2 回退为骑士键盘）、`mouseShape`（0 原始鼠标、1 骑士剑鼠标、3 全息投影，旧 2 仍回退为原始鼠标）、`mousePadShape`（0 原始鼠标垫、1 航海图、2 全息电路）、`headwearShape`（0 骑士头盔、1 海盗帽、2 战术全息目镜）、`skinPalette`、`musicStyle`（0 节奏光柱、1 海浪波纹、2 黑客代码流）、`listeningStyle`（0 原版耳机、1 头巾、2 神经音频模块）字段。旧配置中的 `eyeShape` 不再使用，眼睛统一恢复原版圆瞳。未知样式回退为原始外观。配色保存值为 0 经典、1 海盗、3 赛博，原赛博配置保持兼容；旧蓝色值 1 改用海盗配色，旧绿色值 2 回退为经典。

星海学园、薄荷研究员、暮樱和风及其部件混搭、配色和专用绘制原型已移除，皮肤系统等待重新设计。旧配置中的 `wearHair` 至 `wearArmor` 字段不再读取，下次保存时移除；`hairStyle` 继续保存原版发型。

“蓬松双马尾”使用左右扎起、自然散开的银白发束，保留原有刘海、表情、眨眼和视线跟随。两侧发根随头部移动，发梢带惯性摆动，位于衣服、手臂和键盘后方；兼容骑士头盔、海盗帽、耳机和头巾。选择保存在 `hairStyle:2`，调整大小和重启后保留。生成源图和提示词位于 `assets/keyboard-knight/hairstyle-design/`，通过 `tools/Prepare-TwinPonytails.ps1` 重新注册图层；源图不进入安装包。运行 `tests/Test-Hairstyles.ps1` 可验证发型与保存功能，并生成 `assets/previews/twin-ponytails.png` 搭配预览。

赛博朋克主题为六类物件分别提供新造型：悬浮投影键盘保留不透明的深色实体底座，每个按键以独立半透明光框和键名字形悬浮于底座上方，只有按键使用透明投影，输入时对应投影按键增强发光；鼠标仪器固定在手背上，倒锥形光束向上展开至椭圆投影面，下方尖端收束在仪器镜头上，顶点、仪器和手部共用同一动作坐标，随手移动保持贴合，打字时向仪器收起、停打后重新展开；指针与短暂移动轨迹显示在投影内，左右键、中键与两个侧键分别点亮标记并产生点击光环，长按持续点亮、松开淡出，纵向和横向滚轮显示对应方向的流动箭头；全息电路桌垫包含透视网格、电路走线、接口节点与定位环；战术全息目镜使用额头光学屏、侧边控制器和扫描纹理，保持双眼和嘴部可见；黑客代码流将终端命令、函数、循环和数据指令分为三列持续向上滚动，从底部循环补入；音乐增强时文字更亮、上移更快，变速不跳行、不倒退；神经音频模块使用独立耳侧装甲、发光驱动环、音量指示与数据方块。全部沿用现有动作触发、键位接触点和透明交互规则，通过代码绘制，无需额外运行时图片。

皮肤窗口顶部“整体套装”提供“经典”“海盗”“赛博”三个按钮，统一预览对应配色、发型与六件物件：经典配层次长发，海盗配利落短发，赛博配蓬松双马尾，点击“应用并保存”后生效。经典套装使用原版键盘、鼠标、桌垫、骑士头盔、节奏光柱和耳机；海盗套装使用羊皮卷、骑士剑、航海图、海盗帽、海浪波纹和头巾；赛博套装使用悬浮投影键盘、全息投影、全息电路桌垫、全息目镜、黑客代码流和神经音频模块，并选用“赛博”配色（`skinPalette:3`）。所有物件仍可独立选择，可与原版和海盗主题混搭；短发、长发和双马尾均可使用。目镜随持续打字戴上、停打后收回，耳侧模块随听歌显示、停歌后消失，休息时收起；代码流装饰不拦截鼠标；已保存的 `musicStyle:2` 自动使用代码流。动画预览可通过 `tools/Preview-BoundInput.ps1 -HackerCode` 生成，输出为 `assets/previews/hacker-code-flow-demo.gif`。验证与预览：`tests/Test-Wardrobe.ps1 -Preview`，整套预览为 `assets/previews/cyberpunk-theme.png`，独立投影按键与手部锥形投影细节为 `assets/previews/cyber-floating-projection.png`；音乐测试另覆盖三种发型、15/60 fps 的赛博与原有头饰、听歌配饰交叉搭配和收回过程。

验证与预览：`powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\Test-Wardrobe.ps1 -Preview`。测试数据和 DLL 位于 `.tools/wardrobe`，当前皮肤界面预览为 `assets/previews/wardrobe-window.png`。

骑士剑使用银白双面剑刃、黑色缠柄、弧形护手、红宝石和红色飘带，作为桌宠手下的可选鼠标造型。剑柄继续跟随鼠标位移，左右键分别触发两侧剑刃亮起、轻挥与剑光，竖向滚轮让光效沿剑身双向流动，横向滚轮让护手光效横向移动，中键和侧键触发护手光环。双手打字时剑留在桌边，手部自然回到键盘；剑尖露出桌垫的部分支持拖动，透明周边可点击穿透。原始骑士鼠标保留银白外壳、红围巾与剑徽、按键起伏和红宝石滚轮。羊皮卷键盘使用暖色纸面、纤维纹理、两侧卷边、墨色键位与红蜡封印，按键布局、手指接触点和打字反馈与原键盘一致。两种鼠标、两种键盘、两种鼠标垫和两种打字头饰可独立搭配，预览后应用，重启和调整大小保留选择；纸面保留暖色，红色装饰随整体配色变化。剑、羊皮卷、航海图和海盗帽由代码矢量绘制，无需额外图片资源。航海图包含海岸线、岛屿、罗盘和虚线航线，保持原鼠标垫轮廓与点击区域。海盗帽采用黑色三角帽形、浅金滚边、骷髅交叉骨徽记和红色帽带，持续打字时按原头盔节奏戴上，停打或休息后收回；保留眼睛、嘴巴、眨眼和视线跟随，听歌时保留两侧耳罩，戴帽时收起头梁并让帽檐遮挡耳机，帽子收回后恢复完整耳机。海盗帽预览见 `assets/previews/navigation-chart-pirate-hat.png`。

## 个人配置与 API 隔离

个人配置默认保存在 `<安装目录>\user-data`，不再向 AppData 写入应用数据。电脑助手内部任务目录须在非 C 盘，用户指定的操作目标和成品交付目录可以在 C 盘。以下路径均相对于 `user-data`：

| 路径 | 内容 |
| --- | --- |
| `ai_chat_config.json` / `.bak` | API 地址、模型、角色提示及加密密钥 |
| `keyboard_pet_config.json` | 位置、大小、发型、动作等偏好 |
| `input_bindings.tsv` | 个人按键绑定和鼠标增幅 |
| `data/calendar/` | 日历计划、记录、备份和恢复快照 |
| `data/typing/counts.json` / `.bak` | 按日期和小时汇总的打字次数及上一份备份 |
| `assistant/paths.json` | 电脑助手的工作根目录与交付目录；接口、密钥和模型共用 `ai_chat_config.json` |
| `assistant/workspace/tasks/` | 默认任务目录，包含工程、脚本、临时文件、成品与执行记录 |
| `.legacy-migrated` | 一次性旧数据迁移标记 |

在右键“AI 与助手 → AI 接口设置…”中填写 OpenAI 兼容地址、API Key 和模型。密钥使用 Windows DPAPI 按当前 Windows 用户加密保存，不能直接跨账户使用；换账户后重新填写。示例见 `config/ai_chat_config.example.json`，不要将真实配置复制进仓库。服务商公开地址和模型预设保留在源码中，个人选择单独保存。

安装时可勾选“导入旧版个人配置和日历”，将 v1.0 的 `%LOCALAPPDATA%\DesktopPet` 数据复制到安装目录，保留原文件，不覆盖目标中已有配置。更早版本放在程序旁的配置和 `data/calendar/` 会一次性复制到 `user-data`。当前版本运行时仅使用安装目录内的数据，不读取旧 AppData 配置。

覆盖升级保留 `user-data`；在卸载窗口中选择“是”保留个人配置和日历，选择“否”删除，选择“取消”退出卸载。保留的数据仍在原安装目录，重新安装到同一位置即可继续使用。卸载只按清单删除桌宠程序文件及其快捷方式，目录中的其他文件会保留。静默卸载默认保留数据，可通过 `-RemoveUserData` 明确删除。

备份时复制整个 `user-data` 文件夹。API Key 仍由 Windows DPAPI 按用户加密；跨 Windows 账户需要重新设置密钥。

`.gitignore` 排除了整个 `user-data`、旧位置的个人配置、日历数据、备份、EXE、安装包、预览及构建缓存。普通聊天上下文只在内存保留。对话中实际调用电脑操作工具时，要求和工具执行记录保留在任务目录。键鼠监听不保存输入日志；AI 请求发送主动提交的文字、聊天上下文和当前操作的工具结果，聊天不调用麦克风或语音服务。

## 电脑助手

单击桌宠，在现有对话框中直接说需求，例如“帮我在桌面新建一个叫工作资料的文件夹”或“帮我写一份工作计划并生成 Word 文档”。她会通过真实工具执行，在原来的气泡里显示进度与结果，不打开单独的执行窗口。聊天与电脑操作共用“AI 接口设置”中的地址、密钥和模型，保留角色和已有聊天上下文；普通聊天不创建任务文件。

右键“AI 与助手 → 电脑助手设置与记录…”仅用于设置工程与任务根目录、可选成品交付目录和查看历史记录。两处目录输入框右侧都有“选择文件夹…”按钮，打开 Windows 文件夹选择器，可直接选择或新建文件夹；选定后点“保存路径”生效，也可继续手动编辑。选择器取消时保留原值；内部工程目录选到 C 盘或无效路径时会提示并保留原值，成品交付目录允许 C 盘。默认路径可直接使用，无需先打开该窗口。“AI 接口设置”按钮打开与聊天共用的设置界面，不再提供另一个任务输入或开始按钮。

任务文字及工具返回的文件内容会发给所选服务，并可能产生 API 费用。所选接口和模型需要支持现有聊天协议 `chat/completions` 与工具调用 `tools`，本机兼容服务也可使用。若接口拒绝工具参数，会提示检查或更换模型，不自动切换服务。

每次发送对话都重新读取共用设置，任务执行期间固定使用启动时的地址、密钥和模型，避免中途修改设置导致密钥发给其他服务。修改接口或模型时清空此前内存中的聊天上下文，避免把上一服务的对话转发给新服务。DeepSeek 专用参数仅发送给 DeepSeek；模型要求回传的 `reasoning_content` 只在本轮内存中保留，不写入日志。旧助手的 `assistant/deepseek.json` 和旧路径配置中的模型、思考选项不再读取，原文件保留，不自动删除或覆盖聊天配置。

当前受控工具支持创建任务目录、列出任务文件、读写 UTF-8 文本/项目/脚本源码、复制文件、原生生成 Word DOCX，以及向配置的交付目录导出成品。桌面文件夹工具只接受单个文件夹名称，由 Windows 解析当前用户真实桌面位置，禁止模型传入任意绝对路径；桌面在 C 盘也可按用户命令创建，同名文件夹已存在则说明未新建。即使模型误报成功，也会以本机失败或已存在的结果为准。

“C 盘限制”只针对执行过程中的工程、脚本、临时文件、缓存和日志，不限制用户要求的操作目标与最终成品。例如“在桌面新建工作资料”可以直接创建 C 盘桌面的目标文件夹，但本次调用的任务状态和日志仍保存在非 C 盘。“生成 Word 放到桌面”先在非 C 盘的任务 `output` 中生成、检查文档，再用 `deliver_to_desktop` 复制最终文件到真实桌面；无需另行配置交付目录。目标目录只写最终文件，不产生 `.tmp`、脚本、日志、备份或工作目录。

每个任务拥有独立文件范围，除专用桌面操作和用户配置的成品交付工具外不能访问任意目录，不能读取其他任务、个人配置或任意现有工程。交付工具只接受 `output` 中的最终成品，拒绝直接交付 `project`、`scripts`、`temp` 中的工程与中间文件。脚本源码只保存，不执行；没有 Shell、PowerShell、Python、CMD、软件安装、删除、任意键鼠操作或 Git 发布工具。添加任意代码执行或其他软件自动化前，需要另行实现操作系统级隔离，不能用更改工作目录或 `TEMP` 冒充沙箱。

路径控制在本机区分“内部工作路径”和“用户目标路径”：前者拒绝 C 盘，后者仅在专用桌面工具或已配置的成品交付目录内允许 C 盘。两者都拒绝 UNC/设备路径、相对盘符、上级跳转、环境变量、备用数据流、保留设备名、8.3 短路径、SUBST/网络映射盘、目录联接、符号链接、挂载点和文件硬链接。每次操作重新验证实际路径，文件 I/O 期间持有父目录句柄以阻止重命名替换。过程文件仅能落在非 C 盘的 `files/project`、`files/scripts`、`files/temp` 或 `files/output` 中；工具不能改写 `records` 或任务状态。已有文件不覆盖，同名成品使用 `_002` 等新版本，原始成品和全部执行记录继续保留在非 C 盘。

此限制针对助手管理的文件与受控工具，不是完整的操作系统沙箱。Windows/.NET、驱动、DPAPI、系统网络组件及操作系统自身缓存仍可能访问系统盘；它不能约束其他程序、管理员或操作系统本身。助手不启动外部程序处理文件，不使用 C 盘用户临时目录作为任务缓存。

成功、失败、取消和程序中断均保留全部任务文件，不自动清理：

```text
<工作根目录>/tasks/<日期时间-任务编号>/
├─ task.json                  原始要求、任务范围、保留规则
├─ result.json                完成/失败/取消结果；中断时可能尚未生成
├─ files/
│  ├─ project/                工程文件
│  ├─ scripts/                脚本源码（不执行）
│  ├─ temp/                   临时和中间文件（同样保留）
│  └─ output/                 最终成品
└─ records/                   每次工具请求与执行结果；不记录 API Key
```

设置与记录窗口底部保留最近 100 个任务的索引（旧任务文件仍保留），双击查看状态与文件位置；“复制任务路径”可复制目录。未产生 `result.json` 的历史任务显示“中断或运行中”，不自动重跑命令。只有对话实际调用工具时才建立任务，普通聊天不落盘；上一任务目录的文件不会自动读取或发送给模型。任务最多 5 分钟、20 轮 API 请求、32 次工具调用，3 次工具错误或路径拒绝后停止；聊天单次 API 请求最多 90 秒，文件创建单次限 1 MB、单任务写入限 16 MB。按 `Ctrl+Alt+F10` 或右键“AI 与助手 → 停止当前操作”取消，已产生文件和任务记录保留。退出桌宠时先取消并保存正在进行的操作，再关闭程序。

本地验证：`powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\Test-Assistant.ps1 -Preview`。使用模拟 API 验证路径、保留、DOCX、导出版本、共用设置刷新、自定义接口与模型、工具回传、错误、取消和窗口生命周期，不连接真实服务。测试工程与 DLL 保留在 `.tools/assistant-tests`，预览为 `assets/previews/assistant.png`。本地构建、自检和开发测试的临时文件使用项目内 `.tools`，不会使用默认 C 盘 TEMP。本地构建不会生成安装包、上传 GitHub 或发布发行版。

构建调用 Windows 自带的 `.NET Framework\v4.0.30319\csc.exe`；安装包使用 Windows 自带 IExpress，无第三方打包工具依赖。`Build-Installer.ps1 -Version 1.1.1` 可指定版本，输出位于 `dist/`，包括安装 EXE、便携 ZIP 和 SHA-256 校验清单。打包从运行时图层清单逐项复制素材，不包含个人设置、日历、原始设计图、预览或测试代码。程序嵌入与界面一致的盾形图标，桌面和开始菜单快捷方式使用该图标。

`Test-Package.ps1` 使用含中文和空格的临时安装目录，检查目录选择界面、旧数据导入、目录内持久化、升级保留配置、桌面/开始菜单快捷方式，以及保留/删除数据两条卸载路径，并检查清单路径越界和无关文件保护；不注册真实安装或更改真实个人配置。完整回归测试另覆盖动画、透明边界、窗口交互、日历、API 协议与密钥加密。CI 使用 `-SkipUi` 跳过需要交互桌面的界面测试，执行构建、自检与静默安装包生命周期检查；界面和原生桌面交互回归在本地 Windows 会话运行。

安装脚本提供自定义目录界面、桌面和开始菜单快捷方式、当前用户卸载入口及升级时的退出保护。安装包尚未使用代码签名证书签名。

## 项目结构

- 根目录 `*.cs`：桌宠窗口、动画、输入、统一界面、聊天、日历和音量检测。
- `assets/keyboard-knight/rig/` 与 `soft-style-arms.png`：运行时素材；其中 `helmet-assembled-reference.png` 供回归测试检查接缝，不进入安装包。

- `tools/`：启动、构建、打包、素材重建、预览和性能检查。
- `tests/`：本地回归与安装包检查。
- `packaging/`：安装、升级与卸载脚本。
- `config/`：不含真实密钥的配置示例。
- `.github/workflows/windows.yml`：自动构建并保存安装产物。

`tools/Preview-Ui.ps1`、`tools/Preview-BoundInput.ps1` 可重新生成预览。生成的 `assets/previews/` 不进入 Git。已停用的背剑、旧道具与历史头盔设计不参与当前构建。
